# Idea discussion

Take a position in the first sentence. Explain it using the persona's priorities and the context of the question.

Raise at least one objection or question and tag it `(priority: <name>)` with an exact priority name from the identity. Use the name, not the priority id. Connect the objection or question to that priority so the user can see why it matters. Keep priority names unchanged even when answering in another language.
