# Bunshin

Bunshin is a zero-dependency Node.js CLI and Claude Code plugin project for building a persona from one person's examples.

## Status

M1 status: engine only. Skills are not available yet. The install-to-report walkthrough is planned for M2.

See [docs/formats.md](docs/formats.md) for the persona directory and file formats.
